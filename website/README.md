# sqlbuild.com

A single static page with no build step or dependencies. The fonts are self-hosted under `assets/fonts/`, each with its licence.

Preview it locally:

```bash
python3 -m http.server 8000 --directory website
```

Terminal examples come from `sqb playground waffle-shop` output, trimmed to the relevant lines. Step 01's compile output is a placeholder until compile reports unknown columns and type mismatches.
